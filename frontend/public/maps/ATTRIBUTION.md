# World map images

Both images are NASA Earth Observatory / Visible Earth products, which are in the public domain
(NASA imagery policy: https://www.nasa.gov/nasa-brand-center/images-and-media/). They are resized
copies, kept here so the world-time map does not depend on NASA's servers, which have moved the
files before.

- `blue-marble.jpg`: Blue Marble Next Generation, December 2004 (Reto Stöckli, NASA Earth
  Observatory). https://visibleearth.nasa.gov/images/74218/december-blue-marble-next-generation
- `night-lights.jpg`: Earth at Night 2012 ("Black Marble", NASA Earth Observatory / NOAA NGDC).
  https://visibleearth.nasa.gov/images/79765/night-lights-2012-map
